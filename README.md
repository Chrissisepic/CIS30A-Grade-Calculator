# CIS 30A - Grade Calculator & Performance Tracker

## Project Overview
This Python application calculates course averages, assigns letter grades with academic feedback, and exports a summary report to a text file. Built using Object Oriented Programming principles, custom modules, and built-in error handling.

## Project Structure
- `main.py`: Primary application entry point, user input loop, and file output handler.
- `grade_utils.py`: Custom module containing student classes (`Student`, `CourseCategory`, `HonorsStudent`) and grading logic functions.
- `Course Project Part 1_ by Christopher Gonzalez (1).pdf`: Executive program description and overview.
- `Flow Chart.drawio.pdf`: Visual logic diagram of the application.

## How to Run
1. Ensure `main.py` and `grade_utils.py` are saved in the same folder.
2. Run `main.py` using Python 3 / IDLE.
